Extensions adapt Spacedrive to new file types and workflows without growing the
default runtime. They run as sandboxed WASM modules and use explicit host
capabilities.

An extension can teach Spacedrive how to understand a specialized file while
leaving filesystem identity, permissions, jobs, and storage safety in the core.

## What extensions can add

- File-kind detection from names, MIME data, magic bytes, and provider metadata
- Typed metadata facets and search fields
- Preview renderers, thumbnails, proxies, transcripts, and thumbstrips
- Durable jobs and user-invoked actions
- Source adapters and byte providers
- Content, record, or standalone models
- Sidebar views, inspector sections, and context-menu commands

File-kind support and preview support share one contract. A handler declares
what it recognizes, which capabilities it provides, and how the interface
degrades when the extension is absent.

## Example uses

### Photos

A Photos extension imports an existing photo-library source without moving its
files. It can retain faces, places, albums, edits, and asset relationships as
typed metadata, then add People and Places views.

### Studio media

A media extension can recognize camera formats, extract technical metadata,
generate persistent proxies and thumbstrips, and stream the correct byte ranges
to a video preview.

### Research archives

An archive extension can ingest a provider into ordinary files, preserve
provider metadata as facets, extract citations, and add a focused view over the
same source records.

## What remains in core

Extensions do not replace:

- source and record identity;
- authorization;
- content verification;
- durable job lifecycle;
- file mutation safety;
- library and source sync;
- audit and provenance.

Those rules remain uniform across every extension.

## Capability grants

An extension declares the smallest access it needs. Grants can include:

- read selected source scopes;
- write an extension-owned storage scope;
- attach a declared model to records or content;
- request network access to named hosts;
- dispatch registered jobs or actions;
- contribute declared interface surfaces.

Installation shows these grants before code runs. Removing an extension revokes
its runtime access without deleting its durable data by surprise.

## Distribution

Extensions are ordinary signed packages. You can install one from a local file,
source repository, or URL and verify its identity and requested capabilities.
Spacedrive does not require a managed storefront.

The same compiled WASM module runs on every supported host when it uses portable
capabilities. Platform bridges expose registered macOS, Windows, and Linux file
handlers as evidence without giving them ambient authority.
